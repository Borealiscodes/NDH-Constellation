# **1. Executive Summary**

This case study documents an interpretive misalignment event involving GitHub Copilot and the NDH‑Constellation visual ecosystem. Contrary to initial impressions, Copilot did not "fail" or "collapse." This case study clarifies the nature of the mismatch, updates the ontology analysis, and provides recommendations for safely interacting with PNGs inside GitHub Copilot.

# **5. Recommendations for Working With PNGs + GitHub Copilot**

## **5.1 Use Copilot‑Friendly PNGs When You Want Interpretation**
Copilot understands:

- arrows  
- labels  
- simple hierarchies  
- linear causal flows  

When you want Copilot to "understand" a diagram:

- flatten recursion  
- remove expressive geometry  
- avoid neon‑kawaii overlays  
- use explicit labels  
- avoid symbolic operators

## **5.3 Avoid Mid‑Operation File Moves**
Copilot's repo agent can desync when:

- a file is moved mid‑operation  
- a blob SHA changes  
- a path disappears during a multi‑step action  

Best practice:

- move the file manually  
- commit the change  
- then ask Copilot to continue  

---

## **5.4 Use Copilot for Code, Not Constellations**
Copilot excels at:

- refactors  
- file operations  
- documentation  
- code generation  
- workflow analysis  

It struggles with:

- symbolic systems  
- expressive geometry  
- constellation‑grade architectures  

Use each tool for its domain.
