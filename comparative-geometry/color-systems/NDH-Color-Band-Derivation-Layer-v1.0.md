# ⭐ **1 — Purpose**

The Color‑Band Derivation Layer (CBDL) defines:

- how NDH‑Constellation color‑bands are **derived**  
- how color is **reverse‑engineered** from anatomy  
- how color is **mapped** to Deca‑Map axes  
- how color is **assigned** to subsystems  
- how color is **generated** for MRI overlays  
- how color is **generated** for drift zones  
- how color is **generated** for stability gradients  
- how color is **generated** for confidence gradients  

This artifact does **not** apply color.  
It defines the **rules** for color generation.

Color will be applied in **Artifact 5 — Color‑Aligned Final Report v1.1**.

---

# ⭐ **2 — Color‑Band Derivation Principles**

NDH‑Constellation color‑bands must:

- be **diagnostic**, not expressive  
- be **derived**, not invented  
- be **machine‑readable**, not decorative  
- be **non‑activating**, not operational  
- be **governance‑altitude**, not Zen‑altitude  
- be **consistent** across all subsystems  
- be **stable** across all drift events  

Color is a **governance encoding**, not an aesthetic choice.
