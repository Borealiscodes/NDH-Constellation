The SID Header must appear **at the very top of every NDH‑CONSTELLATION artifact**, before:


# 🧱 **3 — Why SID Must Be Above Operators**

### **3.1 Altitude Declaration**  
Operators live at **Altitude 4**, but the SID Header declares:

- altitude span  
- lineage type  
- epoch span  

Without SID, operators have **no altitude context**.

### **3.2 Governance Enforcement**  
SID enforces:

- invariants  
- dignity constraints  
- stability envelopes  
- adjacency integrity  

Operators must be governed by these rules.

### **3.3 Provenance Anchoring**  
Operators must be traceable to:

- Serenity‑Manifold substrate  
- Sensory Aperture spec  
- AGL integration spec  
- Phase 10 sequencing  
- Triadic‑Core invariants  

SID provides this anchor.

### **3.4 Collapse Prevention**  
If operators appear before SID, the artifact risks:

- expressive drift  
- relational drift  
- adjacency drift  
- collapse‑continuity violations  

SID prevents this.
