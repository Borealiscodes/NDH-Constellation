# ⭐ 3 — Binding Rules

### **Rule 1 — Disclaimer is the root spine**  
All three documents must reference:

```
NDH-Unified-Disclaimer-And-BoundaryDeclaration-v2.0.md
```

### **Rule 2 — Binding is one-directional**  
Documents may reference the disclaimer,  
but the disclaimer **must not** reference the documents.

This prevents recursion.

### **Rule 3 — Binding is non‑constitutional**  
Binding does **not** elevate any document into governance.

### **Rule 4 — Binding is altitude‑bounded**  
Binding applies only within:

- Constellation  
- Stability  
- Comparative  
- Alignment  

### **Rule 5 — Binding is non‑recursive**  
Binding must not generate:

- index‑about‑index  
- disclaimer‑about‑disclaimer  
- roadmap‑about‑roadmap  
- audit‑about‑audit  

### **Rule 6 — Binding is Omnibus‑compatible**  
The Index may be referenced in:

```
NDH-Comprehensive-Omnibus-v1.0.md
```

but must not be absorbed into it.
