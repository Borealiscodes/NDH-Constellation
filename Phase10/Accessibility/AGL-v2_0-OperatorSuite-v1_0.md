### 🌌 AGL v2.0 operator suite — formal spec

#### 0. Purpose

The AGL Operator Suite v2.0 defines the **four canonical accessibility operators** that regulate cognitive load, emotional load, adjacency, and structural exposure across NDH‑CONSTELLATION, TIDS, PLATFORMS, ZEN‑BRIDGE, and RESEARCH‑PILOT, using Sensory Aperture and Serenity‑Manifold as substrates.

All operators must satisfy:

- Meaning Invariant  
- Duality Invariant  
- Holonomy Invariant  
- Stability Invariant  
- Adjacency Integrity  
- Dignity Constraint  

If any invariant fails, the operator chain must halt and route to Calm Basin.

---

#### 1. Operator definitions

##### 1.1 A‑Simplify

**Role:** Reduce cognitive and emotional load.

- **Input:** state \(s\), cue vector \(\chi\), volatility profile \(\nu\)  
- **Output:** simplified state \(s'\) with reduced complexity and volatility  
- **Binding:** Calm Basin (β₀), Sensory Aperture (χ, ν)  

Constraints:

- must not remove meaning  
- must not collapse duality  
- must reduce \(\nu\) within basin envelope  
- must increase perceived clarity  

---

##### 1.2 A‑Expand

**Role:** Add safe context and gentle breadth.

- **Input:** state \(s\), cue vector \(\chi\), holonomy signature \(\eta\)  
- **Output:** expanded state \(s'\) with additional context, bounded by stability  
- **Binding:** Wonder Basin (β₁), Sensory Aperture (χ, η)  

Constraints:

- must preserve core meaning  
- must not exceed volatility envelope  
- must maintain \(\eta\) above basin threshold  
- must avoid overwhelm and coercive detail  

---

##### 1.3 A‑Reframe

**Role:** Shift perspective without adjacency drift.

- **Input:** state \(s\), cue vector \(\chi\), adjacency field \(\phi\)  
- **Output:** reframed state \(s'\) with altered lens but stable core  
- **Binding:** Curiosity Basin (β₂), Sensory Aperture (χ, φ)  

Constraints:

- must preserve semantic core  
- must not introduce manipulative adjacency  
- must keep \(\phi\) within basin bounds  
- must support exploration, not pressure  

---

##### 1.4 A‑Surface

**Role:** Reveal underlying structure safely.

- **Input:** state \(s\), cue vector \(\chi\), holonomy signature \(\eta\), adjacency field \(\phi\)  
- **Output:** surfaced state \(s'\) with visible geometry, relationships, and invariants  
- **Binding:** Reflection Basin (β₃), Sensory Aperture (χ, η, φ)  

Constraints:

- must not expose destabilizing detail without basin support  
- must preserve holonomy loops  
- must maintain adjacency integrity  
- must support integration, not collapse  

---

---

#### 3. Crossmap interaction

Each operator must register with AGL crossmaps:

- **Tile Crossmap:** operator affects adjacency tiles via \(\phi\)  
- **Operator Crossmap:** operator sequencing must preserve collapse‑continuity  
- **Path Crossmap:** operator chains must maintain holonomy paths via \(\eta\)  
- **Narrative Crossmap:** operator outputs must maintain narrative coherence via \(\chi\)  
- **Stability Crossmap:** operator activation must remain within volatility envelopes via \(\nu\)

---

#### 4. Failure behavior

On invariant failure:

- operator chain halts  
- basin transition halts  
- telemetry is suppressed  
- user is routed to Calm Basin  
- no expressive activation occurs  

This is mandatory for all AGL operators.
