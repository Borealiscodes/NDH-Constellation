# 1 — Purpose

The NDH‑CONSTELLATION Sandbox is a **controlled, governance‑grade environment** for:

- testing **frameworks against frameworks**,  
- validating **topology**, **classification**, **ethics**, **tone**, and **invariants**,  
- running **TTTTTTP audits concurrently**,  
- comparing **computer‑detected issues** vs **lineage‑known issues**,  
- ensuring **high‑end artifacts** do not break NDH coherence.

This is **not** NDH‑SIMULATION‑SUITE.  
This is **not** RESEARCH‑PILOT.  
This is **not** TIDS.

This is a **CONSTELLATION‑lane testing manifold**.
