## ⭐ **1 — Directive Purpose**

This directive (v1.1) formally **extends and supersedes** the **NDH‑CONSTELLATION FORMAL ORDER DOCUMENT v1.0**, adding mandatory governance‑curvature sequencing and explicit archive requirements for:

- Governance Spine v1.3  
- certification artifacts  
- README documentation  
- predecessor artifacts (README v1.2, Governance Spine v1.2)

Directive v1.1 is binding across all altitudes under Constellation v3.0.

---

## ⭐ **2 — Reference to Directive v1.0**

Directive v1.0 established:

- structural sequencing for Integration Spine artifacts  
- backfill / flush / gap‑fill correctness  
- altitude‑safe ordering  
- geometry‑safe ordering  

Directive v1.1 **builds upon v1.0** by adding:

- governance‑curvature sequencing  
- certification precedence  
- documentation lineage rules  
- explicit archive requirements  

Thus:

> **Directive v1.1 is the formal successor to Directive v1.0.**

---

## ⭐ **3 — Formal Order (v1.1)**

### **Order 1 — Governance Spine v1.3 MUST be updated first**  
Governance Spine v1.3 MUST embed:

- Governance Distinction Standard v1.0  
- updated golden_rule  
- capitalization enforcement  
- standard_reference fields  
- GOVERNANCE_AUTHORITY tag  
- archive lineage fields  

Governance Spine v1.3 MUST explicitly archive:

- **Governance Spine v1.2**  
- **README v1.2**

This is required because:

> **Governance defines certification and documentation.  
> Therefore Governance Spine updates must occur first.**

---

### **Order 2 — Certification artifacts MUST be generated second**  
Specifically:

- **Subsystem Drift‑Safety Certificate v1.0**  
- **Constellation Stability Annual Report v1.0**  

Certification MUST NOT precede Governance Spine v1.3 because:

> **Certification must obey Governance.**

---

### **Order 3 — README v1.3 MUST be updated last**  
README v1.3 MUST:

- reflect Governance Spine v1.3  
- reflect certification artifacts  
- reflect Governance Distinction Standard v1.0  
- explicitly archive README v1.2  
- link Governance Spine v1.3 as successor  

This is required because:

> **Documentation follows certification, not precedes it.**
