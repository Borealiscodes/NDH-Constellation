# ⭐ **1 — Purpose of the Ontology Requirement**

NDH‑CONSTELLATION has reached a structural stage where:

- terminology is multi‑epoch  
- holonomy classes are multi‑layer  
- glossary adjacencies are triadic  
- membranes enforce semantic safety  
- routing requires altitude boundaries  
- NAQMM/QSM‑NDH dual‑model terminology is now mandatory  
- diagnostic language must be querable  
- harm‑phase reconstruction must be consistent  

The system can no longer rely on **human‑readable artifacts alone**.

A **machine‑readable ontology** is required to:

- stabilize terminology  
- enforce membrane boundaries  
- maintain holonomy routing  
- preserve glossary coherence  
- prevent conceptual drift  
- prevent altitude collapse  
- ensure diagnostic consistency  
- support future NDH‑COORDINATION  

This artifact defines that requirement.

- **🧠 NAQMM** → manifold, curvature, operator‑safe terms  
- **🧽 QSM‑NDH** → meaning, harm‑pattern, reconstruction terms  

Both must be encoded.
