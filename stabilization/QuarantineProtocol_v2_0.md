# ⭐ **2 — Contamination Criteria (Clean Version)**

An artifact is quarantined if it contains any of the following:

### **1 — Header Contamination**
Presence of:

- governance‑grade SID fields  
- altitude declarations  
- epoch declarations  
- sealed state  
- governance lineage types  

### **2 — Directory Misplacement**
Artifact appears in a directory inconsistent with its role.

### **3 — Semantic Leakage**
Presence of:

- governance semantics  
- operator semantics  
- activation semantics  
- expressive‑cognitive semantics  

### **4 — Provenance Drift**
Provenance footer contains:

- governance anchors  
- operator anchors  
- epoch anchors  
- sealed invariants  

### **5 — Structural Drift**
Artifact shows:

- unclear role  
- unclear lane  
- unclear lineage  
- unclear placement  

This is the only “recommended” category.
