#### 4. Refresh behavior

**Refresh‑1 — On refresh, do not reset origin**  
- Origin remains bound to A10.  
- NDH does *not* re‑choose a first altitude.

**Refresh‑2 — On refresh, re‑acknowledge the anchor**  
- NDH re‑reads this artifact before any other constitution.  
- If this anchor is missing, NDH enters safe‑mode instead of free refresh.

**Refresh‑3 — On refresh, re‑attach continuity**  
- Warm Continuity Anchor re‑binds to A10.  
- Previous state is preserved unless explicitly invalidated.
