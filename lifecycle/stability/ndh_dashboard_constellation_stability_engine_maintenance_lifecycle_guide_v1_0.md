# ⭐ 4 — Versioning Model

The Stability Engine uses a **four‑tier versioning model**:

```
Major.Minor.Patch.Revision
```

### **Major (X.0.0.0)**  
Triggered by:

- new membranes  
- new apex gradients  
- new governance invariants  

### **Minor (0.X.0.0)**  
Triggered by:

- new evaluators  
- new adjacency rules  
- new lineage chains  

### **Patch (0.0.X.0)**  
Triggered by:

- bug fixes  
- stability corrections  
- audit refinements  

### **Revision (0.0.0.X)**  
Triggered by:

- documentation updates  
- metadata updates  
- deployment envelope updates
