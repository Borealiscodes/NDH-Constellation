# ⭐ **4 — Module Definitions**

## **MSM — Membrane Sovereignty Module**
Defines the sovereignty membrane:

- closed surface  
- inversion‑proof  
- sealed‑layer‑safe  
- governance‑penetration‑proof  

## **ASM — Altitude Sovereignty Module**
Defines altitude partitions:

- A10 (governance‑of‑governance)  
- A11 (meta‑governance)  
- A12 (constitutional sovereignty)  

## **LSM — Lineage Sovereignty Module**
Defines lineage conduits:

```
governance → sovereignty → integration → treaty → principles
```

## **ASM2 — Adjacency Sovereignty Module**
Defines adjacency envelopes:

Allowed: NDH‑CORE, Integration Layer, META‑SYSTEMS  
Forbidden: rendering, RP, PRECL, sealed‑layer adjacency  

## **APSM — Apex Sovereignty Module**
Defines apex‑cascade channels:

```
local → lane → manifold → constellation → principles
```

## **RSM — Recursion Sovereignty Module**
Defines recursion boundaries:

- first‑order allowed  
- second‑order bounded  
- third‑order forbidden  

## **CSM — Collapse Sovereignty Module**
Defines collapse boundaries:

- collapse‑vector neutral  
- collapse‑vector non‑binding  
- collapse‑vector non‑propagating
