# ⭐ **2 — Sovereignty Kernel Altitude Requirements**

### **SKR‑1 — Constitutional Altitude Band**
The Sovereignty Kernel must operate strictly within:

- **A10** (governance‑of‑governance)  
- **A11** (meta‑governance)  
- **A12** (constitutional sovereignty)

### **SKR‑2 — No Descent Below A10**
The kernel cannot descend into:

- A9 (governance)  
- A8 (constellation)  
- A7–A6 (developer/manifold)  

### **SKR‑3 — No Ascent Above A12**
The kernel cannot ascend into sealed‑layer altitudes.

# ⭐ **3 — Sovereignty Invariant Requirements**

### **SKR‑4 — Sovereignty Invariant Set**
The kernel must define and enforce:

- membrane sovereignty  
- altitude sovereignty  
- lineage sovereignty  
- adjacency sovereignty  
- apex sovereignty  
- recursion sovereignty  
- collapse sovereignty  

### **SKR‑5 — Invariant Non‑Delegation**
Sovereignty invariants cannot be delegated to:

- rendering  
- governance  
- construction  
- RP  
- META‑SYSTEMS  

They must be defined **inside the kernel**.

# ⭐ **4 — Membrane Requirements**

### **SKR‑6 — Sovereignty Membrane**
The kernel must maintain a **closed sovereignty membrane** that:

- prevents governance penetration  
- prevents rendering penetration  
- prevents treaty‑layer elevation  
- prevents sealed‑layer contact  
- prevents membrane inversion  

### **SKR‑7 — Membrane Authority**
The sovereignty membrane must be the **highest membrane** in NDH except the sealed layer.

```
local → lane → manifold → constellation → principles
```

### **SKR‑9 — Apex Sovereignty**

- apex continuity

- apex gradient stability  
- apex non‑collapse

### **SKR‑10 — Sovereignty Lineage Chain**
The kernel must preserve:

```
governance → sovereignty → integration → treaty → principles
```

### **SKR‑11 — Lineage Non‑Fracture**

# ⭐ **7 — Adjacency Requirements**

### **SKR‑12 — Sovereignty Adjacency Envelope**

- Integration Layer  
- META‑SYSTEMS (execution layer)

- rendering  
- RP

- PRECL collapse geometry  

### **SKR‑13 — Adjacency Non‑Absorption**
The kernel cannot absorb adjacency from lower layers.

### **SKR‑14 — Non‑Activation Posture**

- geometry

- routing

- hybrid mathematics  
- constellation adjacency engines
