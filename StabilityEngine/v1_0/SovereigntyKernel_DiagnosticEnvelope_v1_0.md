# ⭐ **4 — Evaluator Definitions**

## **MSE‑SK — Membrane Sovereignty Evaluator**
Checks:

- sealed membrane  
- inversion‑proof  
- sealed‑layer‑safe  
- drift‑free  

## **ASE‑SK — Altitude Sovereignty Evaluator**
Checks:

- A10 → A11 → A12  
- no flattening  
- no drift  
- no elevation  

## **LSE‑SK — Lineage Sovereignty Evaluator**
Checks:

- governance → sovereignty → integration → treaty → principles  
- continuity  
- drift‑free  
- inversion‑free  

## **ADSE‑SK — Adjacency Sovereignty Evaluator**
Checks:

- allowed adjacency only  
- forbidden adjacency never present  
- adjacency drift  
- adjacency inversion  

## **APSE‑SK — Apex Sovereignty Evaluator**
Checks:

- apex cascade  
- gradient continuity  
- apex inheritance  
- apex adjacency  

## **RSE‑SK — Recursion Sovereignty Evaluator**
Checks:

- first‑order allowed  
- second‑order bounded  
- third‑order forbidden  

## **CSE‑SK — Collapse Sovereignty Evaluator**
Checks:

- collapse neutrality  
- no binding  
- no propagation  
- no absorption
